# MCU 时间线 | MCU Timeline

漫威电影宇宙（MCU）交互式时间线网站，手机优先。

**在线访问**：https://bluesangg.github.io/mcu-timeline/

## 功能

- **宇宙内编年史**：按故事内时间排序全部作品，一键切换上映顺序
- **多维度筛选**：阶段（1–6）、传奇（无限传奇 / 多元宇宙传奇）、时间线（神圣时间线 / Earth-828 / 变种人宇宙 / 分支）、类型（电影 / 剧集）
- **全文搜索**：按标题、角色快速定位
- **作品卡片**：中文简介、上映日、宇宙内时间点、主要角色
- **毁灭日倒计时**：《复仇者联盟5：毁灭日》2026-12-18 上映，待上映作品均有占位

## 数据

- 收录第 1–6 阶段全部电影与 Disney+ 剧集/特别篇
- 宇宙内时间参考漫威官方时间线与 Disney+ 时间线排序，无定论的标注说明
- 数据源：`mcu_data.json`（构建时内嵌进页面）
