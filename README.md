# MCU 时间线 | MCU Timeline

漫威电影宇宙（MCU）交互式时间线网站，手机优先。

**在线访问**：https://bluesangg.github.io/mcu-timeline/

## 功能

- 动态首页：活动路线的下一部作品、海报与观看进度同步更新；路线完成后显示完成状态。
- 观看路线：固定收录无限传奇的 23 部电影，提供上映顺序与故事时间两种路线；可预览、主动开始、查看完整清单或剩余作品。
- 无剧透 / 剧透版：默认只展示基础资料；开启完整剧情需确认。无剧透搜索不匹配剧情与人物信息。
- 本机进度：标记已看、撤销、只看未看与已看清单；切换路线保留记录。
- 全部作品目录：68 部现有资料，支持搜索、排序及阶段、传奇、类型等筛选。宇宙筛选仅在剧透版显示。
- 作品视觉：已核对 10 部作品的官方海报链接，图片失败时显示文字版；其余作品暂用文字版。

## 数据

- 收录第 1–6 阶段全部电影与 Disney+ 剧集/特别篇
- 宇宙内时间参考漫威官方时间线与 Disney+ 时间线排序，无定论的标注说明
- 当前数据源：`data/catalog.json`；D01 使用保留原资料的兼容格式，由 ES module 加载。
- 运行时资料仍使用兼容格式，事实审核尚未完成；双模式已接入界面与搜索。故事顺序路线沿用现有目录，不代表逐条事实核验已完成。
- 新模型：`docs/specs/catalog.schema.json`。完整 Draft 2020-12 与合成样例检查已加入工具链，尚未用于运行时资料。

## 本地开发与校验

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run check
npm run dev
```

静态开发服务默认端口 8000，可用 `PORT` 调整；支持项目根及 `/mcu-timeline/` 子路径。
`npm run check` 包含兼容数据结构/日期/id 校验、新模型合成样例校验，以及 17 项数据、DOM 与 HTTP 回归检查。
DOM 检查使用 jsdom，不代表真实浏览器/手机视觉验收。当前无新增部署 workflow。

## 视觉验收与素材

- `tests/visual.html` 在同源 iframe 中提供 320、390、768px 的实际 CSS 视口，便于检查真实窄屏布局。
- 素材链接及官方来源记录在 `src/artwork.js`；海报版权属于 Marvel / Disney，本站不会将其标记为原创或开放许可素材。
