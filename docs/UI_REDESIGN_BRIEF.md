# MCU Timeline 视觉升级提案

状态：影院叙事作为开发方向；尚未修改线上界面。2026-10-01。

本提案根据现有线上首页制定。它要求移除现有界面的超大宣传标题、红色粗边框与首屏全量筛选，并更新旧视觉规范中的色彩、排版及导航；观看路线、时间线与剧透控制的功能目标继续有效。

## 当前问题

- 超大标题、倒计时和红色装饰争抢注意力，用户进入后仍需自己判断看什么。
- 筛选面板占据大块首屏空间，阶段、传奇、宇宙、类型同时出现，阅读负担高。
- 作品卡片主要依赖文字和边框，缺少作品视觉与一致的阅读层级。
- 数据库浏览功能丰富，但缺少有明确起点的观看旅程。

## 推荐方向：影院叙事

采用暖黑背景、象牙白文字和少量朱红强调色。作品视觉承担氛围，标题、留白和对齐承担层级。红色仅用于当前状态与少量关键提示。作品海报或背景图需要单独确定可使用的素材来源；未经确认的素材不得直接成为生产依赖。

用户已授权直接提交并委托设计判断。本轮采用影院叙事作为开发方向，不再以选择备选风格作为前置条件。以下给出这一方向的实施要求。

## 首屏与信息顺序

以 390 × 844 手机视口为主，同时支持 320px 至桌面宽度。

1. 顶栏：小型品牌标识、搜索入口、明确的“无剧透 / 剧透版”切换。
2. 主区域：一句观看导向标题、一部推荐作品、作品名与必要基础信息、唯一主按钮。
3. 辅助区域：首次观看与宇宙编年史的路线入口；详细筛选从时间线页进入。
4. 导航：发现、时间线、我的进度。当前项用形状或文字状态识别，不能仅依赖颜色。发现对应首页；时间线对应原全部作品目录；我的进度承载活动路线及进度管理。观看路线页继续从发现和我的进度进入，旧页面链接保持兼容。

无观看记录时，主按钮为“从这里开始”，推荐来自已定义的首次观看路线。有活动路线且存在未看作品时，主按钮为“继续观看”，显示当前路线下一部未看作品。只有零散已看记录而无活动路线时，仍提供选择路线，不能自动推断活动路线。没有下一部时，显示路线完成与选择其他路线的入口。标记已看是独立操作，不得让“继续观看”自动修改进度。本站提供观看导航，按钮不得暗示本站播放影片。

倒计时不占据默认首屏；若保留，放在经过日期核验的待上映区域。统计数字不作为主视觉。

## 视觉约束

| 项目 | 实施要求 |
| --- | --- |
| 色彩起点 | 背景 #101113，表面 #191B1F，正文 #F2EEE7，强调 #D6453D；这些是初始令牌，最终组合需要对比度验证 |
| 排版 | 中文使用清晰的系统无衬线栈；正文 15–16px、行高 1.6；手机主标题 28–32px；不使用超大宣传字占满首屏 |
| 空间 | 手机左右留白 20px；区域间距 28–40px；组件内部间距 12–20px；桌面内容最大宽度约 1200px |
| 层级 | 优先使用间距、字重和字号；其次用细分隔线；只有需要独立交互边界时使用容器 |
| 图片 | 预留稳定宽高比，加载前不跳动；文字背景必须保证可读；无图时采用简洁文字版，保留作品名和主操作 |
| 控件 | 触控区域至少 44 × 44px；可见焦点；筛选打开后可关闭、清空、应用并回到原滚动位置 |
| 动效 | 仅用约 160–220ms 的淡入或状态过渡；遵从 prefers-reduced-motion；不增加无目的自动播放 |

桌面使用作品视觉与文字并列的首屏布局，路线在下方展开；不能简单把手机内容拉宽。浏览作品的区域保留紧凑列表或网格，但不让首页退化为筛选后台。

## 剧透是全局规则

默认无剧透。作品名、年份、类型、时长等基础信息可显示；剧情摘要、人物关系、事件结果、彩蛋与会泄露剧情的推荐理由必须经过独立安全字段或访问规则控制。无剧透模式不应把完整剧情隐藏在 DOM、工具提示、可访问标签、搜索摘要或分享文案里。

没有经过核验的无剧透摘要时只显示基础信息。切换模式后首页、搜索、时间线与详情立即一致。首次切换剧透版时解释影响并提供返回操作。URL 与本地偏好优先级遵循状态规范，不得由单个组件自行决定。

## 交付顺序

1. 按影院叙事方向建立手机首页与桌面首页参考或可运行设计原型；生成图片只是设计参考，不能视为已实现，图片生成不可用不阻塞原型开发。
2. 更新 PRODUCT_UI.md 的最终令牌、结构和交互规格，建立首页可运行原型。
3. 接入真实作品、路线与进度状态；验证未开始、进行中、全部完成、加载失败和无图五种状态。
4. 将搜索与高级筛选移到明确入口，统一时间线、详情与进度的视觉系统。
5. 验证剧透规则、可访问性、响应式表现，再用实际浏览器截图审查并提交变更。

## 验收标准

- 390 × 844 首屏能识别推荐作品、剧透模式和主操作；主按钮不被固定导航遮挡。
- 320、390、768、1440px 宽度没有横向溢出，长中文作品名不截断关键含义。
- 键盘可完成搜索、筛选、模式切换和进度修改；弹层管理焦点并支持 Escape 关闭。
- 正文符合 WCAG AA 对比度；图片、颜色与动效不是信息唯一载体。
- 作品图加载失败时仍可选择路线与查看作品；不出现空白主区域。
- 无剧透检查覆盖可见内容、DOM、可访问文本、搜索结果与分享元信息。
- 实际截图分别检查手机与桌面；自动测试通过不等于视觉验收通过。
- 原有作品、排序和数据加载行为保持可用；任何新的推荐逻辑需独立说明与验证。
