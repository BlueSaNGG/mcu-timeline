# 页面与组件规格

> 2026-10-01 视觉升级：以 [UI_REDESIGN_BRIEF.md](../UI_REDESIGN_BRIEF.md) 为当前视觉与首页信息架构的优先规范，采用影院叙事方向。本文涉及旧色彩、字体、间距、首页布局及导航的冲突项由新规范覆盖；数据、路线逻辑、进度管理与剧透安全要求继续有效。此更新是设计文档提交，线上 UI 尚待实现。

需求编号 UI-*。MVP 没有海报依赖，先以清晰文本完成核心任务。基于当前站点风格执行以下默认方案，用户反馈后可在日志中提出具体修订。

## UI-01 全局布局与样式

| 项目 | 确定值 |
| --- | --- |
| 主题 | 固定深色；bg #101116，surface #191b22，surface2 #24262f |
| 文字 | 主文字 #f7f5f1，次文字 #b2b4bf；危险/强调 #e51b23，焦点 #65adff |
| 容器 | 最大 1180px；手机左右 16px，桌面 24px |
| 间距 | 4/8/12/16/24/32/48px；组件内边距 16px |
| 圆角 | 方角风格，控件最多 4px；不随意改成圆润玻璃卡片 |
| 字体 | 保留 Noto Sans SC、Barlow Condensed；加载失败使用系统 sans-serif |
| 正文 | 14px，行高 1.65；主操作 14–16px；主要说明不得低于 12px |
| 标题 | 手机 H1 32px/1.2；桌面 H1 48px/1.1；H2 24px；卡片标题 20px |
| 操作区域 | 按钮最小高度 44px；焦点描边 3px，偏移 3px |
| 断点 | <768px 手机单列；768–1023px 中屏；≥1024px 桌面 |
| 动效 | 非必要动画不加；减少动态效果时关闭滚动/转换动画 |
| 布局稳定 | 状态变化不把用户滚动到页顶；操作行有足够高度，长中文可换行 |

红色不单独表达状态，必须有文字；对比度需实际检查。倒计时是次要内容，不使用每秒 aria-live。宇宙颜色沿用当前色系，另有文字标签。

## UI-02 导航与首页

全局顺序：
1. 站点名“MCU 时间线”；导航“首页 / 全部作品 / 观看路线”。
2. 剧透双选控件及简短当前状态。
3. 当前页面主内容。
4. 数据核实日期、来源口径、进度管理入口。

手机导航可换行，不能横向溢出。首次进入标题“你的下一部漫威，从这里开始”，一句说明“选好路线，记录已看，也可以按故事时间查作品。”
- 无活动路线：主要按钮“开始无限传奇路线” → 路线页；次要按钮“查全部作品” → 目录。
- 有活动路线且未完成：主要卡片显示路线名、已看/总数、下一部的安全标题；按钮“继续观看” → 路线页定位下一部。
- 路线完成：显示“这条路线已完成”；按钮“查看完整路线”；不自动重置进度。
- 只有零散已看：显示“已记录 N 部”，仍提供选择路线，不能擅自推断活动路线。
- 页尾可显示下一部已核实电影的日期倒计时；未知日期不倒计时，目标到期后不擅自宣称已上映。

390×844 首屏必须看到主操作和剧透模式。不让英雄大标题、倒计时或四组筛选占满首屏。

## UI-03 目录

从上到下：
- H1“全部作品”、结果计数。
- 剧透模式使用全局入口，不再放第二份独立设置。
- 有标签的搜索框：“搜索作品或角色”，占满可用宽度。
- 排序：上映顺序 / 故事时间 / 推荐观看。默认上映顺序；旧编年史入口映射“故事时间”。
- 手机“筛选”按钮展开阶段/传奇/宇宙/类型，显示已启用条件数；桌面展开。
- “隐藏已看”独立勾选项；“清除筛选”清空筛选/搜索/隐藏已看，保留排序与剧透偏好。
- 结果列表；手机一列，桌面最多两列；故事时间时按宇宙及时间分组，避免跨宇宙假先后。

卡片顺序：标题/英文名 → 类型/宇宙标签 → 上映日期/故事时间 → 当前模式简介 → 操作。
操作：已看切换、展开资料、无剧透模式下“展开本作剧透”。
轻量资料面板包含字段来源、中性争议说明与角色；不用等完整详情页才能提供证据。
完整模式卡片显示审核过的剧情摘要；长结局/彩蛋可在资料面板折叠。未录入则提示“详细剧情待补充”。

空结果：“没有匹配作品”，说明“试试其他关键词或清除筛选”，提供清除按钮。
加载失败：“作品资料加载失败”，提供重试；不能回退显示可能过时的假数据。
结果计数用礼貌播报，搜索输入最多 200ms 防抖；输入法组合输入结束再更新。保持输入焦点。

## UI-04 路线页

H1“第一次看：无限传奇电影上映路线”。
顺序：适用人群/收录口径 → 开始或继续按钮 → 已看/总数与剩余时长 → “只看剩余/完整路线” → 编号作品列表 → 来源。
- “开始这条路线”保存 activeRouteId；进入页面本身不自动改变活动路线。
- 每项：编号、安全标题、时长、入选理由、已看按钮。
- 下一部 = 路线中首个未看作品。全已看时显示完成状态。
- 只看剩余不会重编号；标记后下一部变化，通过温和提示表达，焦点仍可操作。
- 无时长则“时长待核实”；合计显示“已知约 X 小时 Y 分，另有 N 部时长待核实”。
- 剧透模式改变理由文本，不改变成员、顺序或进度。
- 提供“复制路线链接”；成功/失败提示。复制失败显示可手动复制的地址。

## UI-05 提醒、单部展开与进度管理

完整模式首次提醒文案：“将显示已上映作品的结局、身份反转和彩蛋。”按钮“开启完整剧透 / 取消”。取消/Escape/关闭均回到无剧透；焦点回切换按钮，禁止弹窗背后操作。
单部按钮：“展开本作剧透（含结局与彩蛋）”；展开后“收起本作剧透”。跨作品内容按 STATE 规则处理。

“管理本机进度”面板：
- 说明“保存在此浏览器；清除浏览器数据可能丢失，建议导出。”
- 导出 JSON、恢复 JSON、清空进度。
- 恢复先校验，再显示“将替换 N 条已看记录，忽略 M 个未知作品”；取消不写入。
- 清空确认只删除观看记录/活动路线，不清空剧透偏好；清空前可导出。
- 存储失败显示“暂时无法保存；当前操作仅在本次页面有效”，按钮仍能用。
