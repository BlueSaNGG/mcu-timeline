## 固定产品边界

MVP：
- 保留现有 68 个作品 id；中文目录、既有筛选和三种明确排序口径。
- 默认无剧透/完整剧透双模式、单部展开及偏好保存。
- 未看/已看、本机存储、隐藏已看、导出及安全恢复。
- 唯一精品路线：无限传奇电影按北美首次院线上映顺序。按官方范围核实成员；日期冲突记录来源。
- 首页、目录、路线页；轻量作品展开面板。完整独立作品页后续再做。
- 手机/键盘可用、hash 直达、静态 GitHub Pages。
- 数据核实或明确未知；逐项审核记录。

后续范围：其他路线、在看/想看、分集进度、独立详情/角色页、海报、图谱、SEO 静态页、账号和运行时 AI API。
不实现占位但可点击的假按钮。未开发的后续功能不出现在生产导航。

## 完成定义

每个工作包必须提供：
- 实现的需求编号、变更文件、检查命令与真实结果。
- 涉及 UI 时的当前截图：至少 390×844 与 1440×900；记录对应状态。
- 已知问题、未验证事项、回滚方式。
- 执行日志。没有测试/浏览器能力则记录阻塞，不能用“看起来正确”替代。
- 未解决数据冲突不伪造；局部未知可继续，关键路线证据不足阻塞路线发布。

视觉依据：沿用现有页面的红黑、方角、字体风格，并遵循 PRODUCT_UI 的尺寸规格。它是确定的实现基准，不是已选定的设计图片，也不是完美视觉的证明。若要大幅重设计，先取得视觉参考并确认，不让 agent 自由替换风格。

工程验收通过可交付待审预览。用户测试另记 pending/pass/fail；无法招募参与者不得伪造结果。合并和发布依据当次用户授权，文档提交不是后续自动发布授权。
