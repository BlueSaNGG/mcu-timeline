## DEV-01 建议模块

- app.js：协调加载、路由与渲染。
- catalog.js：加载与可见投影，不将原始敏感字段直接传给 safe view。
- spoilers.js：可见性公式、确认/切换。
- search.js、sorting.js、routes.js：纯业务规则。
- persistence.js：读取/写入/导入校验，返回结果对象，不吞错误。
- router.js：parse/serialize；路由未知与 URL 清理。
- views/：可聚焦组件；不重复实现剧透策略。
- styles/tokens.css 与 components.css：有限样式系统。
- tests/unit/、tests/e2e/：只测试实际风险与行为，不镜像实现细节。

对具体模块名可做等价调整，但接口、验收与责任不能丢失。新增依赖先说明解决的问题，使用官方文档及锁文件；不随意引入后端或替换整个技术栈。
